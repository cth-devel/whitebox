# WhiteBox — Courier & Logistics Aggregator

A modern, interactive single-page website for **WhiteBox**, a courier and logistics aggregator based in Saudi Arabia.

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Font:** Inter (via next/font)

## Brand Colors

- **Primary:** `#f72a42` — Buttons, accents, key branding
- **Secondary:** `#d7d7d3` — Backgrounds, borders, subtle sections
- **Text:** Deep charcoal/black for readability

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Sections

1. **Navigation** — Sticky, transparent header with glassmorphism on scroll
2. **Hero** — Headline, CTAs, floating 3D-style box and delivery route animation
3. **Partner Carousel** — Infinite horizontal scroll (FedEx, Aramex, DHL, Naqel, SMSA, J&T Express)
4. **Services** — Bento grid (Domestic & International, Global Import, Door-to-Door, Protective Packaging)
5. **Why WhiteBox** — Interactive cards (Home Delivery, Speed, Low Cost, Quality Packing)
6. **Location Focus** — “Headquartered in Saudi Arabia, Serving the World”
7. **Contact** — Contact form + Get a Quote calculator (client-side only)
8. **Footer** — Links, social icons, “Made in KSA” badge

## Features

- Mobile-first, fully responsive
- Reveal-on-scroll animations (Framer Motion)
- Custom cursor (desktop only; hidden on touch devices)
- Smooth scroll (CSS)
- Glassmorphism and bold typography
